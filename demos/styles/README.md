# Démos · Styles en React (Jour 2, module 06)

Les trois projets du formateur, tels quels :

| Projet | Contenu |
|---|---|
| [`intro-tailwind-css`](intro-tailwind-css) | Tailwind CSS v4 avec Vite : classes utilitaires, `@theme`, `@apply` |
| [`intro-charka-design`](intro-charka-design) | Chakra UI v3 : composants, props, thème (tokens) |
| [`cars-css`](cars-css) | De Figma au code : carte catalogue (en live) et carte détail (exercice 9), en CSS |

## Lancer un projet

```bash
cd intro-tailwind-css   # ou intro-charka-design, cars-css
npm install
npm run dev
```
