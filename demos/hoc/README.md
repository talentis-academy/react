# Démo · Higher-Order Component

Le HOC `withAuth` : la vérification « accès refusé / session expirée » centralisée pour les pages A et B. La version wrapper (`AuthWrapper` avec `children`) est en commentaire. Code du formateur.

Fichiers à regarder : `src/components/Home.jsx`

## Lancer la démo

```bash
npm install
npm run dev
```
