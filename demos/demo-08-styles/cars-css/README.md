# Démo · De Figma au code (cartes en CSS)

Les deux cartes de la maquette Figma, en React + CSS (code du formateur) : la carte catalogue (Card Car, faite en live) et la carte détail (Card Details, exercice 9).

Fichiers à regarder : `src/components/Home.tsx`, `src/components/styles.css`.

Maquette : https://www.figma.com/design/QQo8OKT7hF053RIvEclLrh/Untitled?node-id=22-191&m=dev

## Lancer la démo

```bash
npm install
npm run dev
```
