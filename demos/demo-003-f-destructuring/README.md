# Démo 003-F · Destructuring

*Formation 003 · slide 27*

Le destructuring ES6 : tableaux, rest, spread et objets.

## Lancer avec Quokka (VS Code)

Ouvrir `destructuring.js`, puis Cmd + Shift + P → **« Quokka.js: Start on Current File »** : le résultat de chaque `console.log` s’affiche au bout de la ligne (voir la Démo 003-B pour installer Quokka).
Sans Quokka : `node destructuring.js` dans le terminal.
