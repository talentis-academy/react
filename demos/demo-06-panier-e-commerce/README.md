# Démo · Panier e-commerce (conditions)

Un panier e-commerce simple pour pratiquer le rendu conditionnel : state `myProducts`, `if / else` avec `let content`, puis le même résultat avec `? :` et `&&`.

```bash
npm install
npm run dev
```

Fichier clé : `src/components/Panel.tsx`.
