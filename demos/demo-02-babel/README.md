# Démo · Babel : du JSX au JavaScript

*Formation 002 · slides 14-15*

Deux façons d’écrire le même composant : en JSX (converti par Babel) et à la main avec `React.createElement`.

| Fichier | Rôle |
|---|---|
| `index.html` | La démo complète : `ComponentA` (JSX) et `ComponentB` (`React.createElement`) |
| `script.html` | Page de départ vide (React + ReactDOM + Babel déjà chargés) pour coder en direct |

**Ouvrir** : double-cliquer sur `index.html` (ouvrir dans le navigateur), changer la ligne `root.render(...)` pour comparer.

Babel en ligne : https://babeljs.io/repl
