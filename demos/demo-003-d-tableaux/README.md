# Démo 003-D · Les tableaux

*Formation 003 · slides 15-16*

Rappels JavaScript sur les tableaux, sans React.

## Lancer avec Quokka (VS Code)

Ouvrir un fichier, puis Cmd + Shift + P → **« Quokka.js: Start on Current File »** : le résultat de chaque `console.log` s’affiche au bout de la ligne (voir la Démo 003-B pour installer Quokka).
Sans Quokka : `node 01-tableau.js` dans le terminal, ou copier le code dans la console du navigateur (F12).

| Fichier | Contenu |
|---|---|
| `01-tableau.js` | Tableau simple : créer, `indexOf`, ajouter, supprimer… (version complète, commentée) |
| `02-tableau-objets.js` | Tableau d’objets (`id`, `name`) |
| `03-a-vous.js` | Pour les étudiants : le code de `01-tableau.js` sans les explications, à compléter |

Étape par étape (les lignes ajoutées et le résultat attendu dans la console) : `CHANGEMENTS-tableau.pdf` et `CHANGEMENTS-tableau-objets.pdf`.

L’exercice 5 est dans `Exercices/Exercice_05`.

Documentation : https://developer.mozilla.org/fr/docs/Web/JavaScript/Reference/Global_Objects/Array
