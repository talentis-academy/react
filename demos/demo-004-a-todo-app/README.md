# Démo 004-A · Todo App

La Todo App faite ensemble (slide 7) : on charge 10 todos depuis l'API avec `fetch` dans un `useEffect`, et on affiche les titres. Sans loading, sans filtre.

- Le code : `src/components/Todo.jsx`
- L'API : https://jsonplaceholder.typicode.com/todos?_limit=10
- C'est aussi le template de l'exercice 10 (`Exercices/Exercice_10/template`).

```bash
npm install
npm run dev
```
